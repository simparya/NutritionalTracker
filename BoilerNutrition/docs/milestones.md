# CS193 project milestones (one commit each)

1. `chore: initialize project structure and README` — project scaffold, matrix, architecture diagram.
2. `test: verify Purdue menu data access` — document a real request/response or a blocked-access finding.
3. `feat: add daily Earhart menu retrieval` — fetch a menu for a selected date.
4. `feat: add interactive meal selection` — Bash CLI for breakfast, lunch, and dinner.
5. `feat: show food nutrition details` — parse available values using jq.
6. `feat: search food items by name` — keyword search for the loaded menu.
7. `fix: handle missing data and API errors` — error paths and input validation.
8. `test: add CLI and parsing test cases` — exercise expected and invalid inputs.
9. `docs: add installation and usage examples` — complete README and known limitations.
10. `docs: add final demonstration notes` — short video outline and presentation notes.

Use one commit when you finish each milestone. Do not mark unimplemented work as finished.
